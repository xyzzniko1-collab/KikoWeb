Panduan Instalasi & Penggunaan

Ikuti langkah mudah berikut untuk menjalankan aplikasi POS Ayamclup di perangkat Anda.

Cara "Instal" & Menjalankan Aplikasi

1
Simpan File HTML

Salin seluruh kode HTML ini, lalu simpan di komputer Anda dengan nama file index.html atau pos.html.

2
Buka di Browser

Klik dua kali file tersebut. File akan langsung terbuka di browser favorit Anda (Google Chrome, Microsoft Edge, Safari, atau Firefox).

3
Siap Digunakan!

Aplikasi ini 100% serverless (tanpa server). Semua data menu dan riwayat transaksi disimpan aman di memori browser Anda (LocalStorage).

Panduan Penggunaan Fitur

  • Mesin Kasir (POS): Klik menu pada katalog cepat atau gunakan form "Input Manual" untuk memasukkan item baru secara instan ke keranjang belanja.
  • Pembayaran & Cetak Struk: Masukkan jumlah uang tunai yang diterima, sistem otomatis menghitung kembalian. Klik "Proses Transaksi" untuk memunculkan struk belanja siap cetak.
  • Kelola Menu: Gunakan tab "Kelola Menu" untuk menambah menu baru (bisa pakai URL gambar) atau menghapus menu bawaan dari database lokal Anda.
  • Riwayat Transaksi: Semua transaksi tercatat rapi. Anda bisa melakukan cetak ulang (re-print) struk kapan saja atau menghapus seluruh riwayat untuk memulai hari baru.
